# 抖音账号分析

一个独立的 AI Agent 技能，通过正常浏览器会话读取抖音公开主页与作品，分析账号定位、选题分布、文案结构和互动表现。

## 包含内容

- `SKILL.md`：完整采集流程、分析要求和输出规范。
- `agents/openai.yaml`：技能名称与默认调用提示。

## 使用方法

将本仓库作为 `douyin-account-analyzer` 技能导入支持 SKILL.md 的 AI 工具；具体安装位置以你使用的工具为准。也可以让具备浏览器能力的 AI 读取本仓库的 `SKILL.md`，按其中流程执行。

调用示例：

```text
使用 $douyin-account-analyzer 分析这个抖音公开账号的作品与文案：<主页链接>
重点分析最近 30 条作品的选题、开头钩子、发布节奏和高互动作品共性，并给出 5 个原创文案模板。
```

## 运行条件

- AI 工具需要具备浏览器控制能力；本仓库不内置浏览器、采集程序或第三方 API。
- 需要登录或验证时，由使用者在自己的浏览器中完成。
- 默认分析最近 30 条公开作品，明确要求时最多 100 条。

## 分析范围

输出账号定位、选题占比、文案钩子与 CTA、关键词和标签、发布节奏、互动表现、头部作品共性、原创模板与数据局限。主要结论需附可核验的作品链接和数字。

仅分析页面可见的发布描述与数据，不包含视频下载、语音转写、字幕提取或自动发布；不可见字段保留为缺失，不虚构数据。

这是独立整理的浏览器分析技能，不包含 douyin-cli，也不需要安装它。技能本身不包含账号凭据或历史分析数据。
